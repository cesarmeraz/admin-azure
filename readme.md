# Admin Azure
Administrative scripts, templates, and documentation for running my personal Azure subscription. I have just one for now and consolidating cross-cutting operations will lead to faster discovery and improved practices. 

# Toolset

- Ubuntu 24.04.5 LTS
- VS Code 
- az cli

# Structure
This repo contains a series of stories dealing with a specific, well-scoped use case, and all artifacts - unless shared - should be contained in a directory devoted to that use case.

## Stories
Each story should be its own folder named with lowercase letters with dashes for spaces, kebob-style. The folder contains all related scripts and docs. Keep it focused on one objective.
